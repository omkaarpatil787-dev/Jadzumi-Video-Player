# Reference mapping

All six attached references are preserved byte-for-byte. HTML is used only as design input.

| Reference | Current native implementation | Remaining |
|---|---|---|
| Home/library | pale-blue rail, search/categories, featured art, continue rows | real collection/poster shelves, mini-player, typography/motion refinement |
| Movie details | native hero, sample progress, temporary favorite, chapter placeholder | real chapters/cast/storage/track data |
| TV details | native series hero and episode list | real seasons, watched state, track defaults |
| Cinema player | clearly labeled future destination | full player and overlays |
| Settings/About | categories, persisted theme/reduced motion, privacy/credits | other controls and full Expressive motion |
| Folders/storage | decluttered two-pane empty state | SAF import/index, real storage and conditional USB |

Colors extracted from references: primary #005BBF, primary container #1A73E8, pale-blue #D0E1FA, canvas #F7F9FC, ink #191C1E. System font is used for this foundation; bundled reference typography is still pending. Artwork is a local copy of three image URLs present in the supplied HTML, used for the personal design preview only. Public distribution requires asset rights review or replacement.

The HTML's v2.4.0/production, checksum, libass, decoder and frame-drop claims are fictional design content and are deliberately not copied as live app claims. The native version is 0.1.0-m1.
