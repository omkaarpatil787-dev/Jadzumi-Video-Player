# Milestone 1 device review — Xiaomi Pad 5

This APK is a UI foundation preview. It cannot play videos yet.

1. Install and launch. Confirm the pale-blue surface, left navigation rail and content fit in landscape without system bars covering controls.
2. Scroll the library repeatedly. Check for jumps, oscillation and stalls. Change between Library, Folders, Settings, Player and Playlists.
3. Search `Chrono`; select Movies (no results), then TV & Anime (one result). Clear search and return to All videos.
4. Open movie and series details; press Android Back. Ensure it returns to the library. Check episode rows are readable.
5. Turn Design preview off. Confirm empty-library copy, with no fake files. Turn it on again.
6. Open Settings → Appearance. Test Light, Dark, AMOLED and System. Force-close/relaunch and confirm the selected theme persists. Test Reduced motion and relaunch persistence.
7. Rotate and try split screen. Check text remains reachable and there is no crash. Narrow layouts are a safety fallback; the polished phone phase is later.
8. Inspect Folders. There must be no fake free-space figures, connected USB or private-folder notice.
9. Increase system font size and verify settings can still scroll. Test TalkBack labels on navigation and favorite control.
10. Report screenshots, device OS version, orientation and steps for any issue. Playback/codec tests are intentionally deferred until their implementation milestones.

Approval gate: wait for Omkar's device feedback, fix/retest defects, then request approval to proceed. A compile pass alone is not device approval.
