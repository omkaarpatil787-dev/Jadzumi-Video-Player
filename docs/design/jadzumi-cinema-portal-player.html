Motion & native implementation notes

Design reference for Kotlin / Jetpack Compose. The portal uses rounded clipping bounds; posters use a shared-element transform; play/pause morphs interpolate two filled shapes; menu/close and expand/collapse interpolate matching stroke paths. Navigation uses a spring-like settling curve. Theme changes use a circular reveal when the View Transition API is available, with a colour/fade fallback. Reduced motion removes spatial travel. The actual Android app should use its real destination and readiness state, retain the existing playback pipeline, and measure frame timing on the Pad 5 and S23. This file does not scan storage, decode media, or implement HDR/audio processing. File properties and titles shown here are demonstration data.
